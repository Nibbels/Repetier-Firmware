## Scope and work

Inventory every definition in Repetier/Constants.h at the integrated baseline. Record consumers (including preprocessor, build flags, UI templates and source-extraction tests) and final disposition. Limit changes to definitions, their owners, direct consumers and affected tests. Preserve numeric values, persistence, pin/retrofit configurations, startup display and host protocol.

- Move BIGC0–BIGC3 to the startup display implementation. Preserve PSTR/PROGMEM placement, glyphs, both LCD widths and version output. Keep the version shared with the host report.
- Separate direct-move behavior (TASK_MOVE_FROM_BUTTON and TASK_MOVE_POSITION_MANUAL) from queued task identifiers. Trace all call sites including numeric arguments and defaults. Use a small explicit type at the direct-move interface and a uint8_t-backed shared task type for producers, queue and executor. Preserve stoppability, release behavior, queue layout and interrupt handoffs.
- Give doEmergencyStop and its callers a typed StopReason. Place MENU_MODE masks with their shared menu-state interface and Z_VALUE_MODE values with the Z-display interface. Verify mask combinations, configuration defaults and stored representations.
- Replace the macro aliases uint, uint8, int8, uint32 and int32 with explicit standard-width types where used. Preserve AVR widths on host and target. Keep axis identifiers and board selectors available to their shared consumers, especially board selection in #if and build flags. Use existing owner headers wherever practical.
- Inspect remaining definitions individually, including stepperEnableDelayMs (shared axis/extruder timing) and IGNORE_COORDINATE (movement API sentinel). Move only where ownership and dependencies are clearer. Explain anything retained.
