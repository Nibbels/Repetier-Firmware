- Status: VERIFIED for integration after Task0019.
- Target: ai-firmware-review. Follow coordination/TASKS.md.

Inspect maintained Repetier C++/header/INO files, starting with BedMatrixDiagnostics.h. Remove orphaned or repeated decorative comment bars and empty comment-only blocks; keep useful section headings. Normalize ordinary human-language line comments to one space after // and an uppercase sentence start where appropriate (e.g. // machmal -> // Machmal). Preserve Doxygen syntax, licenses, third-party notices, tooling directives, commented code, URLs and string literals. No code reformat, whitespace churn outside touched comments, or edits to generated/vendor sources. Be aware of macros, line splices, source-extraction tests and __LINE__.
