### Audit / scope decision

- Keep the existing owners: USART0 byte rings in UsbSerial, frame and serial session plus two parsed slots in GCodeInput, command fields/echo in GCode. ASCII parsing, binary sizing/decoding, and admission have separate responsibilities already. A shared field-descriptor table or a split into more translation units would require extra indirection or duplicate state without demonstrated SRAM/flash/throughput benefit. No public API changes, no dispatch/HAL/Communication edits. Retain the unused public setFormatError() setter identified by Task0004: removing an inline public method has no demonstrated linked saving and is contrary to the frozen interface.
- Preserve M110 reset, M112 reception-time handling, modulo-65536 numbering, duplicate skips, resend/ok order and 30-zero binary resynchronization, 200 ms partial / 1000 ms idle / 2 s busy thresholds, text borrowing until queue drains, and stop-time acknowledgement without enqueue. Keep the ASCII panel-text checksum exception and the flash script's existing shared parser state; changing those is not a structural cleanup.
- One concrete defect warrants a small fix, separate from any architectural rewrite: V2 text framing caps the length-byte-plus-payload contribution at 80 bytes, but the decoder previously used the unchecked declared length for its NUL write. A checksum-valid clipped frame declaring 255 bytes could write outside the 96-byte frame. Reject declarations >=80 through the existing resend path. Correctly framed text of 0–79 bytes and V1 fixed text are unchanged. No new buffers, no UART ISR changes. Do not claim that this covers all malformed-input cases.
- Extend the existing source replay for overlong ASCII and boundary terminator, valid fragmented V2 maximum text, clipped text (80/255) and resync, 256 numbered commands across the 16-bit wrap with slot wrap, and reception-time M112 before command blocking/sequence validation. Keep all existing transcript assertions and UART ring replay. Host test exercises admission, not physical sustained throughput.
