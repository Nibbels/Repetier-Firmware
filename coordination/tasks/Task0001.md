### Linked AVR builds

Arduino CLI 1.2.2, Arduino AVR Boards 1.8.6 and AVR GCC `7.3.0-atmel3.6.1-arduino7` on both checkouts. Each variant was built with the following command and its model definition.

```sh
arduino-cli compile --fqbn arduino:avr:mega:cpu=atmega2560 \
  --build-path "$build" --build-property "compiler.cpp.extra_flags=$flags" \
  --build-property "compiler.c.elf.extra_flags=-Wl,-Map,$build/firmware.map,--cref" \
  Repetier --verbose
```

`flags` was `-DMOTHERBOARD=DEVICE_TYPE_RF1000`, `-DMOTHERBOARD=DEVICE_TYPE_RF2000` or `-DMOTHERBOARD=DEVICE_TYPE_RF2000v2`. The X44 build added `-DNUM_EXTRUDER=1 -DEXT0_EXTRUDER_COOLER_PIN=X44_PIN` to the RF2000 flags.
