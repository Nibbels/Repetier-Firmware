### Conversion and verification

ADC foreground snapshot comes from HAL; 32 ten-bit readings are summed and shifted by 3, producing 0..4092, with ANALOG_REDUCE_BITS=0. Table temperatures are in eighths of degrees C. RF1000 correction is all zeros; RF2000 family uses offsets -2/-4/-6/-8/-10/-10 at 60/80/100/120/140/160 C, interpolates from zero at 0 C, and holds the last offset above 160 C. Preserve both the raw-value semantics and conversion/calibration ordering.

Table 9 has 58 explicit rows and formerly 67 declared. Last explicit entry is (4092, 0), the nine omitted initializers become (0,0). For raw <4092 the loop has already found a greater raw endpoint; for raw >=4092 none of the trailing zero entries can match and the last temperature remains zero. Removing padding therefore retains the conversion including the upper saturation behavior. ELF inspection confirmed all 58 retained pairs byte-identical, all other eleven tables byte-identical, table count only changes 67 to 58, and total linked table bytes 1852 -> 1816. No sensor selection or table point changed.

### Task0010 safety handover (existing behavior, not fixed here)

- Common converted-range predicate is < -10 C or > 300 C, not a raw electrical validity test. At raw 4092, NTC IDs 2,9,10,11,12,13 produce 0 C for both calibrations; at raw 0, IDs 53,60,100 produce 0 C. These values do not trip that predicate. Actual open/short polarity depends on fitted sensor/interface. Do not infer a physically valid sensor from a successful conversion or this range check.
- Unsupported IDs return false; manageTemperatures requests zero duty before continuing. For supported but implausible temperatures the shared error counter delays the fault latch and the regulation path can still run before the latch. Autotune checks unsupported status at entry, but later ignores the return of updateCurrentTemperature; investigate continuous fault and heater authorization. HAL publishes samples without a freshness timestamp. These are source findings; no physical heater-shutdown guarantee.
- Required follow-up: sensor-specific raw validity windows and calibrated range, immediate heat inhibition on invalid/stale data, explicit per-controller fault policy through autotune and normal regulation, fault-latch behavior, test disconnected heaters or instrumented dummy loads. Coordinate with Task0013 for HAL freshness/physical timing. Preserve all profiles and model-specific calibration. See heater safety requirements. Do not classify the existing fault policy as safe solely because conversion replay is green.
