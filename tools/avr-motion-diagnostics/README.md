Important: this is an archival **restricted instruction diagnostic**, not a complete AVR emulator, not a timing/safety certificate and not an automatically discovered CI test. It assumes the two historical layouts, initializes a synthetic move and board pin state, executes one linked performMove, compares logical state and ordered STEP edges, reads packed Flash table values. No asynchronous IRQ dispatch, SEI deferral, autonomous timer/peripheral time model, real serial input, continuous planner/queue simulation or mechanical model. The interpreter uses hand-coded instruction semantics and fixture offsets; audit against instruction-set reference, independently cross-check representative traces, derive/verify struct offsets and pin maps before using it on modified builds. Unsupported instructions fail; do not stub away relevant work. The initial synthetic interval and rate sweep denominator are described in Task0030. No new replay execution or production edit during this archival copy. Use this as a starting point for Task0032, not as proof of whole-system feasibility.
